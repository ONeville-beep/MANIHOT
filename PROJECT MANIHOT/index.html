MANIHOT: Pemanfaatan Hydrochar Kulit Singkong sebagai Komposit Penyimpan dan Penyalur Panas Pasif untuk Perban Terapi Nyeri Sendi Berbasis IoT

Aplikasi web ini berfungsi sebagai instrumen pemantauan dan evaluasi performa termal prototipe komposit Hydrochar Kulit Singkong (penyerap fototermal), Perca Katun Majalaya (matriks penyangga), dan Phase Change Material (PCM) berbasis asam lemak nabati dengan rentang perubahan fase rancangan 38.0–41.0 °C yang diukur menggunakan mikrokontroler ESP32, dua sensor suhu presisi TMP117, serta sensor iluminansi BH1750.

Penafian Ilmiah & Keselamatan (Bukan Perangkat Diagnosis Medis)
Aplikasi ini merupakan perangkat lunak pemantauan prototipe skala laboratorium dan bukan alat medis tervalidasi klinis. Rentang suhu 38.0–41.0 °C adalah parameter rancangan penelitian, bukan jaminan keamanan termal bagi setiap kondisi kulit pengguna. Pemilihan antarmuka di bawah ini ditujukan untuk pemisahan fungsi tampilan pada prototipe (bukan sistem autentikasi keamanan jaringan).

1. Patient Interface (Tampilan Pengguna)

Antarmuka sederhana yang dirancang agar mudah dipahami oleh subjek uji atau pengguna tanpa menampilkan kerumitan teknis.

  • Angka suhu antarmuka kulit berukuran besar (°C)
  • Status suhu terhadap rentang rancangan dalam bahasa sederhana
  • Indikator koneksi perangkat dan deteksi otomatis data kedaluwarsa
  • Peringatan keselamatan langsung apabila suhu melebihi 41.0 °C
  • Kontrol mulai/akhiri sesi pemantauan pasif
Buka Patient Interface

2. Admin Dashboard (Tampilan Peneliti)

Antarmuka teknis lengkap bagi tim peneliti untuk mengevaluasi data sensor mentah, kurva respons termal, dan log sistem.

  • Koneksi Web Bluetooth API (BLE GATT) ke ESP32 & simulator skenario DEMO
  • 9 kartu telemetri: T_material, T_kulit, ΔT, dT/dt aktual, dan iluminansi (lux)
  • 4 grafik real-time Chart.js dengan pembatasan titik memori
  • Panel evaluasi matematis, statistik sesi, dan keterbatasan model fluks kalor
  • Tabel data mentah, ekspor CSV murni, log peristiwa, dan konfigurasi ambang
